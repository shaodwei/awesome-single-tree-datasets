# Contributing

## Add a source

1. Give the primary data link.
2. Describe the measurement method and the measured object.
3. Give the data license from the data source.
4. Give the related paper or project report.
5. Define each count as trees, observations, files, or components.
6. State repeated observations, shared sources, and synthetic components.
7. Update both source catalog formats.

## Add a figure

1. Confirm that the source terms permit publication.
2. Give the source release and source member.
3. State the sampling, units, transforms, and display scales.
4. Keep display changes separate from numerical analysis.
5. Give the source creators and the figure license.

## Write clearly

Use the [writing principles](docs/WRITING_STYLE.md). Keep source titles and IDs unchanged where identification requires them.
Do not include personal acquisition records, private paths, credentials, or raw scan files.
