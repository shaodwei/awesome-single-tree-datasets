# Single Tree Library

Only real measured scans qualify for the measured library. User-generated assets, procedural foliage, synthetic trees and simulated lidar are excluded. QSM/graphs are companion derivatives of the same observations. Organ-level scans and stem-only benchmarks are separate auxiliary resources.
Raw data is immutable. Keep old projects read-only and retain original locations.
Archive root, SSD workspace, file locations, logs and private research metadata live in ignored local files.
Public catalog contains only source URLs, licenses, scientific suitability and portable scripts.
Checksum verification is mandatory before a download enters raw/. Size alone is insufficient.
Never interpret a QSM as a foliated whole tree, a point cloud as a mesh, or a display material as measured spectra.
Do not claim geometric QA or source completeness from the existence of a file.
No source deletion, paid purchases, licensing acceptance on behalf of the user, or requests to authors without explicit instruction.
One writer per folder via AgentHub. Downloader uses the archive lock and must not run concurrently with another downloader.
Use a working Python interpreter; do not rely on a Windows Store stub. Machine-specific paths belong in ignored local records.
Review any engineering changes with Claude Code; no nested bridge calls.
