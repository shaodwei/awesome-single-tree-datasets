# Terms and writing principles

This catalog uses the writing principles of [ASD-STE100, Issue 9](https://asd-ste100.org/about_STE.html).
It is not a certified STE document. Full dictionary compliance has not been certified.

## Principles

- Give one main idea in each sentence.
- Use active voice when the subject performs the action.
- Keep descriptive sentences at 25 words or fewer.
- Keep instructions at 20 words or fewer.
- Give one instruction in each sentence.
- Keep one topic in each paragraph.
- Keep each paragraph at six sentences or fewer.
- Use one term for one technical meaning.
- Define necessary technical names.

Source titles, creator names, IDs, field names, and license text keep their original forms.
The controlled terms below are technical names for this subject.

## Terms

| Term | Meaning in this catalog |
|---|---|
| Biological tree | One living or formerly living tree, independent of its measurement records. |
| Observation | One measurement event or scan group. |
| Tree instance | A source record that assigns geometry to one tree ID. |
| Point cloud | A set of measured or reconstructed spatial points. |
| TLS | Terrestrial laser scanning. |
| MLS | Mobile laser scanning. |
| ULS | Unmanned aerial vehicle laser scanning. |
| ALS | Airborne laser scanning. |
| Lidar | A measurement method that uses laser range observations. |
| QSM | Quantitative structure model derived from tree measurements, usually for wood. |
| Graph | A model of connected tree parts. |
| 3DGS | Three-dimensional Gaussian splatting; an image-based scene representation. |
| Occlusion | A surface is hidden from a sensor view. |
| Leaf-on | Leaves are present during measurement. |
| Leaf-off | Leaves are absent during measurement. |
| Source-table row | One entry in a published source table. |
| Source point | A finite-coordinate point from the selected source member. |
| Display point | A sampled point used in a figure. |
| Vertical extent | Maximum z minus minimum z in the stated point set. |
| CRS | Coordinate reference system. |
| DBH | Stem diameter at the source-defined breast height. |
| PAD | Plant area density; not estimated by scan-point proportions in this catalog. |

The [official writing rules](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) define STE usage in full.
